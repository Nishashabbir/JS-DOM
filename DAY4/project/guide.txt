The story of your mini e-commerce app

Imagine you are building a small online store like Amazon, but very simplified.

You need 3 things:

1.  Products (what you sell)
2.  Cart (what user selected)
3.  UI (what user sees)
 STEP 1: You define the store (DATA layer)
const products = [...]
let cart = [];
What this means in real life:
products = warehouse inventory
cart = shopping basket (empty at start)

 Important idea:

cart is NOT HTML
It is just memory (state)

 STEP 2: You build the page (RENDERING)
renderProducts();
What happens:

JS takes each product and builds HTML:

<div class="card">
  <button class="add-to-cart" data-id="1">

Now the user sees:

 real product cards on screen

 WHY data-id EXISTS (very important)

This is the key confusion.

Problem:

When user clicks a button, JS needs to know:

 WHICH product was clicked?

But buttons don’t automatically know product data.

 Without data-id, you'd have no connection

You would see:

<button>Add to Cart</button>

JS would NOT know:

Is it product 1?
product 2?
 So we attach hidden info:
data-id="3"
Meaning:

“This button belongs to product with id = 3”

 Think of it like a tag:
Button	Tag
Add to Cart	product id = 3
 STEP 3: USER CLICKS BUTTON

Now event happens:

container.addEventListener("click", ...)

Because of event delegation, container catches ALL clicks.

 STEP 4: Identify what was clicked
if (e.target.classList.contains("add-to-cart"))

 “Only continue if a button was clicked”

 STEP 5: Extract product identity
const id = e.target.getAttribute("data-id");

Now:

id = "3"

 JS now knows:

“User clicked product 3”

 STEP 6: Find real product object
const product = products.find(p => p.id == id);

Now JS converts:

id = 3

into:

{ id: 3, title: "Mouse", price: 1500 }
🛒 STEP 7: Add to cart (STATE CHANGE)
cart.push(product);

Now cart becomes:

cart = [
  { id: 3, title: "Mouse" }
]

 THIS is the real shopping basket

NOT HTML

 IMPORTANT DISTINCTION (your confusion)

You said:

“I thought updateCartUI is increasing count, but there is another span”

Let’s clear this.

 HTML PART
<div class="cart">
  Cart: <span id="cart-count">0</span>
</div>

You actually have TWO parts:

Element	Role
div.cart	container (visual box)
span#cart-count	number display
 STEP 8: updateCartUI()
cartCount.innerText = cart.length;
What this means:

 It updates ONLY the number inside span

So:

cart.length = 3

Becomes:

Cart: 3

data-id = tells JS which product was clicked
cart = real stored data (not HTML)
updateCartUI = updates only the number in the span
cart div = just visual container
span = actual number display
