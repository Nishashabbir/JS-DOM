loops *********

You can't directly apply styles or content to the entire collection at once. You need to loop through each element:

 Correct way - Loop through them:
javascript
// Select ALL elements with class "p1"
let allParagraphs = document.getElementsByClassName("p1");

// Then manipulate each one individually

for loop **************
for(let i = 0; i < allParagraphs.length; i++) {
    allParagraphs[i].textContent = "HI it is working smoothly ! ";
    allParagraphs[i].style.fontSize = "12px";
    allParagraphs[i].style.color = "crimson";
}

for each loop :*************************
// we write the foreach loop like this

fruits.forEach(function(???, ???, ???) {

});

// It's like forEach is saying:
// "I'm going to give you 3 things, in this order:
//  1. The current item

 Wrong way - Trying to manipulate the collection directly:
javascript
let allParagraphs = document.getElementsByClassName("p1");
allParagraphs.textContent = "HI it is working smoothly ! "; // ❌ WON'T WORK!
// This tries to set textContent on the COLLECTION itself, not the elements
Modern approach with forEach (using querySelectorAll):
javascript
// querySelectorAll supports forEach directly
document.querySelectorAll(".p1").forEach(paragraph => {
    paragraph.textContent = "HI it is working smoothly ! ";
    paragraph.style.fontSize = "12px";
    paragraph.style.color = "crimson";
});

data attributes in html ****************

What are data attributes?
html
<div data-priority="high">  <!-- This is a data attribute -->
<div data-user-id="123">    <!-- Another example -->
<div data-price="99.99">     <!-- Another example -->
Syntax: data-anything="value"

Always start with data-
Can name them anything after the dash
Store extra information in HTML
Access them easily in JavaScript
instead of writing them in the class , you can separately add them as data attribute 

how to access them : *************
JAVASCRIPT - DATASET PROPERTY
javascript
// How to access data attributes in JS:
task.dataset.priority  // Gets the value of data-priority

// If HTML has: data-priority="high"
task.dataset.priority  // Returns "high"

// If HTML has: data-user-id="123"
task.dataset.userId    // Returns "123" (camelCase after data-)

***************
if (task.dataset.priority === 'high') {
    // Do something for high priority tasks
}
