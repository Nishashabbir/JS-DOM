Important parts of the program 

Is quantity a keyword?

No — quantity is NOT a special keyword in JavaScript.

It’s just a normal property name that the developer chose.

You could rename it to anything:

item.count++
item.qty++
item.numberOfItems++

JavaScript doesn’t care — as long as you're consistent.

 What is existing.quantity++ doing?

If existing looks like this:

{
  id: 101,
  name: "Shirt",
  price: 20,
  quantity: 2
}

Then:

existing.quantity++;

Means:
 Increase quantity by 1

So it becomes:

quantity: 3
 What is { ...product, quantity: 1 }?

This is where the structure part gets interesting.

1. The ...product (spread operator)

This copies all properties from product.

Example:

const product = {
  id: 101,
  name: "Shirt",
  price: 20
};

Then:

{ ...product }

Becomes:

{
  id: 101,
  name: "Shirt",
  price: 20
}
2. Adding quantity: 1

Now this part:

{ ...product, quantity: 1 }

Means:
 Copy everything from product
 AND add a new property quantity

Final result:

{
  id: 101,
  name: "Shirt",
  price: 20,
  quantity: 1
}
 Why not just push product?

If you did:

cart.push(product);

Then:

You wouldn’t track how many items are added
You might end up with duplicates instead of increasing quantity
 Big Idea (Structure Thinking)
product → comes from your product list (no quantity yet)
cart → stores products plus extra info (like quantity)

So you're basically transforming:

product → cart item

by adding:

quantity
 Full Flow in Simple Terms
If item exists:
 Increase its quantity
If item doesn’t exist:
 Copy product + add quantity: 1 and store it

Is .quantity a variable or a method?

Neither.

 It is an object property (a key inside an object).

 Think of objects like labeled boxes

Example object:

const item = {
  id: 101,
  name: "Shirt",
  quantity: 2
};

Here:

id, name, quantity → are properties (keys)
101, "Shirt", 2 → are their values

So:

item.quantity

means:
 “Go inside item and get the value stored under quantity”

 Why can we use dot (.)?

In JavaScript:

object.property is how you access or create properties

So these are valid:

item.quantity = 5;   // set value
item.quantity++;     // increase value

Even if it didn’t exist before, JS allows this:

const item = {};
item.quantity = 1;

Now item becomes:

{ quantity: 1 }
 So is it predefined?

 No — JavaScript does NOT have a built-in quantity

 You are defining it yourself

 Relating to your code
When adding new item:
cart.push({ ...product, quantity: 1 });

You are literally creating a new property called quantity.

Later:
existing.quantity++;

Now that property already exists, so you:
 Access it
 Increase it

 Analogy (helps a lot)

Think of an object like a student record:

student.marks = 80;
student.grade = "A";
marks, grade are not built-in
You just created them

Same idea:

item.quantity = 1;
 Key takeaway
.quantity is:
 Not a keyword
 Not a method
 Not predefined

What is reduce()?

reduce() is an array method used to turn an array into a single value.

 Think: “Take many items → combine them into one result”

 Simple Example
const numbers = [1, 2, 3, 4];

const sum = numbers.reduce((total, num) => {
  return total + num;
}, 0);

Result:

sum = 10
 How it works
numbers.reduce((total, num) => total + num, 0);
total → accumulator (keeps the running result)
num → current item
0 → starting value
Step-by-step:
total = 0

0 + 1 = 1
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
 Why use reduce() in a cart?

In shopping cart code, it’s usually used to calculate things like:

 Total price
const total = cart.reduce((sum, item) => {
  return sum + item.price * item.quantity;
}, 0);
 Total items
const totalItems = cart.reduce((sum, item) => {
  return sum + item.quantity;
}, 0);
 Why not use a loop?

You can use a loop:

let total = 0;
for (let item of cart) {
  total += item.price * item.quantity;
}

 reduce() just does the same thing in a cleaner, more functional way.

 Big Idea

reduce() answers:
 “How do I combine all elements into ONE value?”

 In your cart context

If your cart looks like:

[
  { name: "Shirt", price: 20, quantity: 2 },
  { name: "Shoes", price: 50, quantity: 1 }
]

Then reduce() can:

Calculate total price → 90
Count items → 3
 Mental Shortcut
map() → transform items
filter() → remove items
reduce() → combine items
